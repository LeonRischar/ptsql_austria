# ptsql

# Description
This repo contains the code to calculate the PTSQL in Austria.

# Structure
- data/: contains the data in GTFS format for all of Austria
  - raw/: contains the raw data in zipped as downloaded from https://data.mobilitaetsverbuende.at/en/data-sets
  - extracted/: contains the extracted zip files from the raw data
- src/: contains the code to calculate the PTSQL


# Usage
Run the jupyter notebook to calculate the PTSQL.
